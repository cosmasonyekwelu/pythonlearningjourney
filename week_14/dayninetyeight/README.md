# Day 98: Weekly Project – Production Monitoring Dashboard

## Objective
Integrate monitoring, logging, and health checks into a comprehensive production dashboard for a live trading system.

## Concepts Covered
- **Integrated Observability**: Combining metrics, logs, and alerts into a single viewpoint.
- **System Health Monitoring**: Real-time tracking of error rates, latency, and resource usage.
- **Operational Excellence**: Building the tools necessary to maintain a system 24/7.

## Code Explanation
The `day_ninetyeight.py` script serves as the project orchestrator, demonstrating how a production system integrates structured logging and health monitoring hooks for visibility.

## How to Run
Run the production monitoring demonstration:
```bash
python day_ninetyeight.py
```
