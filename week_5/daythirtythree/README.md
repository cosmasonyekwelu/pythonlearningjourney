# Time Series Analysis for Financial Data

This project provides a comprehensive Python package for performing **advanced time series analysis** on financial datasets.

It is designed for research, trading analytics, and financial modeling applications.

---

## Features

- **Stationarity Testing:** Augmented Dickey-Fuller (ADF) and KPSS tests
- **Seasonal Decomposition:** Trend, seasonal, and residual analysis
- **ARIMA Modeling:** Forecasting based on ARIMA(p, d, q)
- **Volatility Forecasting:** GARCH, EGARCH, and rolling volatility analysis
- **Rolling Metrics:** Real-time volatility, Sharpe ratio, and drawdown tracking
- **Multi-asset Analysis:** Batch data download and comparative analysis

---
