# Day 91: Weekly Project – Cloud-Ready Trading System

## Objective
Integrate all week's learnings into a complete, production-ready trading system deployed to cloud infrastructure with automated orchestration.

## Concepts Covered
- **Microservices Orchestration**: Coordinating multiple services (Market Data, Signals, Execution, Risk) in a distributed environment.
- **Observability**: Implementing comprehensive monitoring and logging across the cloud stack.
- **Production Readiness**: Validating health checks, failover, and throughput in a live-like environment.

## Code Explanation
The `day_ninetyone.py` script serves as the project orchestrator, demonstrating how to deploy and manage the lifecycle of the distributed trading microservices.

## How to Run
Run the cloud system orchestrator demonstration:
```bash
python day_ninetyone.py
```
