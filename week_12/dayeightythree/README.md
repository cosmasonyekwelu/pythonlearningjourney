# Day 83: Monte Carlo Simulations for Uncertainty Modeling

## Objective
Implement advanced Monte Carlo simulation techniques for strategy validation and confidence interval estimation.

## Concepts Covered
- **Price Process Models**: Geometric Brownian Motion (GBM), Heston (Stochastic Volatility), and Jump Diffusion.
- **Bootstrapping**: Using historical returns to generate random paths.
- **Ruin Analysis**: Estimating the probability of significant capital loss.
- **Optimal Position Sizing**: Using simulation-based Kelly Criterion.

## Code Explanation
The `day_eightythree.py` script provides a comprehensive `MonteCarloSimulator` that supports multiple stochastic models and calculates detailed probability distributions for strategy outcomes.

## How to Run
Run the simulation demonstration:
```bash
python day_eightythree.py
```
