# Day 79: Strategy Optimization & Machine Learning

## Objective
Apply advanced optimization techniques and machine learning for parameter tuning and signal generation.

## Concepts Covered
- **Bayesian Optimization**: Efficiently searching parameter spaces for optimal risk-adjusted returns.
- **Genetic Algorithms**: Using evolutionary logic to evolve strategy parameters.
- **ML Signal Generation**: Using ensemble models (Random Forests, XGBoost) to predict price moves.

## Code Explanation
The `day_seventynine.py` script features a `StrategyOptimizer` class demonstrating different optimization methods and an integrated ML pipeline for signal enhancement.
