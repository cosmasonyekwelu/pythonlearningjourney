# Day 81: Market Microstructure & Order Execution

## Objective
Build advanced execution algorithms and analyze market microstructure to minimize slippage and transaction costs.

## Concepts Covered
- **Order Types**: Implementing Limit, Stop, and Iceberg orders.
- **Execution Algorithms**: VWAP (Volume Weighted Average Price) and TWAP (Time Weighted Average Price).
- **Market Impact**: Estimating and minimizing the cost of large trades.
- **Microstructure Analysis**: Analyzing bid-ask spreads and order book depth.

## Code Explanation
The `day_eightyone.py` script features an `ExecutionEngine` that simulates high-fidelity order execution with multiple algorithm options and real-time slippage modeling.

## How to Run
Run the execution algorithm demonstration:
```bash
python day_eightyone.py
```
