# Day 78: Performance Metrics & Analytics

## Objective
Implement comprehensive performance analytics, including attribution analysis, drawdown decomposition, and multi-factor risk models.

## Concepts Covered
- **Advanced Metrics**: Calmar ratio, Ulcer index, and tail risk measures (CVaR).
- **Multi-Factor Risk Models**: Analyzing strategy exposure to market, size, and value factors.
- **Performance Attribution**: Decomposing returns into timing vs. selection skill.

## Code Explanation
The `day_seventyeight.py` script demonstrates an `AdvancedPerformanceAnalyzer` that calculates 50+ metrics and provides statistical significance testing for strategy returns.

## How to Run
Run the performance analysis demonstration:
```bash
python day_seventyeight.py
```
