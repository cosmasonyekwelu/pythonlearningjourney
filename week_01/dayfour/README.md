# Day 04: Control Flow Mastery & Number Guessing Game

**Date:** September 25, 2025

## Learning Objective
To master control flow in Python using conditionals and loops, and apply these concepts to build an interactive mini-project.

## Concepts Covered
- **Conditionals**: `if`, `elif`, `else` for decision making.
- **Loops**: `for` loops for iteration, `while` loops for condition-based execution.
- **Loop Control**: `break` to exit loops, `continue` to skip iterations.
- **Nested Loops**: Loops inside loops (e.g., for multiplication tables).
- **Algorithmic Thinking**: Fibonacci sequence and palindrome checks.
- **Interactive Programming**: Handling user input and exceptions.

## Code Explanation
The `day_four.py` script is divided into three parts:
1. **Control Flow Fundamentals**: Demonstrates temperature classification and various loop types.
2. **Practical Exercises**: Implements classic algorithms:
    - `fibonacci_sequence(count)`: Generates a list of Fibonacci numbers.
    - `reverse_string(text)`: Reverses a string manually.
    - `is_palindrome(text)`: Checks if a string reads the same backwards.
3. **Number Guessing Game**: A complete interactive class-based game:
    - `generate_number()`: Picks a random target.
    - `play_round()`: Handles the guessing logic and provides hints.
    - `update_high_score()`: Persists the best score during the session.

## How to Run
Run the interactive script:
```bash
python week_01/dayfour/day_four.py
```

## Reflection
Building the Number Guessing Game was a great way to combine loops, conditionals, and user input. It's rewarding to see basic concepts come together into a functional program!
