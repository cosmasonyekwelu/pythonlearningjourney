# Day 09: Advanced Conditionals & Loop Mastery

**Date:** September 30, 2025

## Learning Objective
To gain advanced proficiency in control flow using complex conditional logic and sophisticated loop patterns.

## Concepts Covered
- **Conditional Mastery**: Deeply nested `if/elif/else` structures and complex boolean logic.
- **Logical Operators**: Combining conditions with `and`, `or`, and `not`.
- **For Loop Patterns**: Using `range()` with steps and `enumerate()` for index tracking.
- **While Loop Control**: Implementing input validation and termination conditions.
- **Loop Control Statements**: Detailed use of `break`, `continue`, and `pass`.
- **Practical Algorithms**: FizzBuzz, Grade Calculation, and Prime Number checking.

## Code Explanation
The `day_nine.py` script contains three specialized classes:
- **ConditionalMastery**: Focuses on decision-making logic and operator usage.
- **LoopMastery**: Demonstrates various iteration techniques, including `enumerate` and while-loop validation.
- **PracticeExercises**: Contains real-world algorithm implementations:
    - `fizz_buzz(n)`: The classic programming interview challenge.
    - `prime_number_checker()`: Efficiently checks for primes by iterating up to the square root of the number.
    - `number_guessing_game()`: An interactive version of the game with attempt limits and hints.

## How to Run
Run the script to see the demonstrations and algorithm results:
```bash
python week_02/daynine/day_nine.py
```

## Reflection
Nested loops and complex conditions are where logic can get tricky. Using `enumerate()` makes loops much cleaner, and understanding when to use `break` vs `continue` is essential for efficient control flow.
